ℹ Diagnóstico A/M

⚠ Por que a A/M na planilha está zerada?
A coluna "Relação A/M" (col 64 da aba Monitoramento) contém fórmulas que referenciam células de volume do tanque que estão em branco. O valor calculado pelo Excel seria 0 ou erro.

✅ Solução aplicada no BI:
O BI calcula a A/M automaticamente usando: A/M = DQO carga (kg/d) ÷ (SST tanque (mg/L) × Vol reator (m³) ÷ 1000)
Configure o volume do reator acima para obter valores precisos. Com vol = 3.200 m³, a A/M varia de 0,16 a 1,09 no período atual.

📝 SQL para criar a tabela no Supabase:

CREATE TABLE monitoramento_ete (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  data DATE NOT NULL UNIQUE,
  vazao_eb NUMERIC,
  ph_eb NUMERIC,
  dqo_eb_mg NUMERIC,
  dqo_eb_kg NUMERIC,
  vazao_eq NUMERIC,
  sst_mab1 NUMERIC,
  sst_mab2 NUMERIC,
  ph_flotador NUMERIC,
  dqo_flotador NUMERIC,
  sst_tanque NUMERIC,
  ss_proveta NUMERIC,
  ivl_calc NUMERIC,
  ph_tanque NUMERIC,
  dqo_saida NUMERIC,
  sst_efluente NUMERIC,
  efic_dqo_flot NUMERIC,
  efic_dqo_total NUMERIC,
  idade_lodo NUMERIC,
  ivl NUMERIC,
  relacao_am NUMERIC,
  criado_em TIMESTAMPTZ DEFAULT NOW()
);

-- Ativa Row Level Security
ALTER TABLE monitoramento_ete ENABLE ROW LEVEL SECURITY;

-- Permite leitura pública (ajuste conforme necessário)
CREATE POLICY "Leitura pública" ON monitoramento_ete
  FOR SELECT USING (true);

-- Permite inserção autenticada
CREATE POLICY "Inserção autenticada" ON monitoramento_ete
  FOR INSERT WITH CHECK (true);
